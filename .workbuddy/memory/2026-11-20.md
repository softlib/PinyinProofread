# 2026-11-20

## 将 PinyinProofread-java 完整移植到 Delphi 12.2

- 输出目录：`PinyinProofread-Delphi/`，包含 .dpr/.dproj/.rc/.res、src/（uMain/uState/uFileProcessor/uAudio/uRecord）、res/（2 TTF + 2042 MP3 + ICO）、samples/、README.md。
- 对应关系：Main.java→uMain+uState，FileProcessor.java→uFileProcessor，Audio.java→uAudio，Record.java→uRecord。
- 用 RAD Studio 23.0（Delphi 12 Athens）的 dcc32 编译通过；已验证 GUI 启动、HTML 解析/分页、保存回写、翻页索引。
- 关键坑与解决：
  - Delphi 源码含中文必须带 UTF-8 BOM，否则字符串字面量乱码。
  - 用 `CreateNew` 无 DFM 方式创建主窗体导致 EAccessViolation；改为最小 uMain.dfm + `inherited Create(AOwner)` 后正常。
  - 动态数组 2D 用 `array of array of T` 时避免局部变量名 `Pos` 与系统 `Pos()` 冲突（曾导致崩溃），改用 `case` 直接赋值。
  - 分页中共享的空白 Block 不能在 GetPages 的 finally 里 Free，否则 PullBack/Save 访问悬空指针；改为单元级 BlankBlock，随 Clear 释放。
  - brcc32 不支持 PNG-based ICO，需用 BMP(DIB) 格式 ICO（Python 手写）才能编译进 .res。
  - 播放用 Windows MCI (mciSendString) 替代 jaco MP3 player，行为等价、无外部依赖。
- UI 自动化验证：用 ctypes 找窗口/子控件，按 y 坐标区分两个 TEdit（上方为路径框），WM_SETTEXT 设路径 + 真实鼠标 mouse_event 点击「打開」按钮，确认表格显示示例 HTML 真实内容。
- 换行符整改：用户要求全部 .pas/.dpr/.dfm 用硬回车（CRLF）；已将 7 个文件从 LF 统一转为 CRLF（保留 UTF-8 BOM），备份于 `_backup_lineendings_*/`，重新编译零错误零警告。注意：后续编辑这些源码时必须维持 CRLF，勿被工具改回 LF。
- 修复 .dproj 打开报错：错误 -1072896759「缺少所需的空白区」Line14 col53，根因是第14行 Condition 属性里 `or "` 混入多余双引号（属性值内应使用单引号），导致 XML 引号提前闭合。已改为 `or '$(Base)'!=''`，并给 dproj 加 UTF-8 BOM + 转 CRLF；用 Python ElementTree 解析通过。备份 `PinyinProofread.dproj.bak_*`。教训：手写 MSBuild .dproj 时 Condition 属性用双引号包裹、内部字符串一律用单引号，勿混用。
- 修复翻页报「Operation not allowed on a sorted list」：根因 uRecord.Add 中对 `Sorted:=True` 的 TStringList 执行 `Records[Idx] := ...`（TStringList.Put），VCL 规定 Sorted 时 Put/Insert 抛 SSortedListError；首次打开走 Add 正常、翻页更新已存在路径才触发。修复：改为先 `Records.Delete(Idx)` 再 `Records.Add(...)`（Delete/Add 在 Sorted 下合法）。备份 `src/uRecord.pas.bak_*`。已写 TestRecord.dpr 模拟多次翻页验证通过（Get 值正确、无异常），测试后清理。教训：Delphi Sorted TStringList 禁止 Put/Insert/按索引赋值，更新已有键只能 Delete+Add。
- 新增播放高亮：uState 加 `PlayHighlight: Boolean` + `PlayHighlightColor: TColor=clYellow`；uMain.GridDrawCell 中当 `(PlayHighlight) and (ACol=PlayCurCol) and (ARow in [2*PlayCurRow, 2*PlayCurRow+1])` 时用高亮背景画（拼音行+汉字行整列）；ActPlayExecute 开始时置 True+Repaint、暂停时置 False+Repaint，FormClose 也置 False。播放线程原有 PlayTick 回调每读一字更新 PlayCurRow/Col 并 Repaint，故高亮自动跟随朗读移动。已用 UI 自动化+截图验证：高亮逐字移动、暂停后消失。
